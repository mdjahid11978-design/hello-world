# Hello World

A fully upgraded Next.js 14 + TypeScript + Tailwind CSS starter.

## Features

- Next.js App Router
- TypeScript strict mode
- Tailwind CSS
- ESLint + Prettier
- API route (`/api/hello`)
- GitHub Actions CI
- Vercel-ready

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## API

- `GET /api/hello` → `{ "message": "Hello, world!" }`
